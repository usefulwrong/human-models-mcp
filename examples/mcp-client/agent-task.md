# Independent agent task

Use the connected Human Models MCP server and the human-models-mcp,
scientific-interpretation and scenario-authoring skills. Discover models,
capabilities and scenarios. Run loaded_elbow; retrieve numerical results and an
actual image, inspect it and find relevant scientific sources. If a scenario
provides an external experimental comparison, discover and run it, retrieve its
reference/plot and explain what is compared and what remains unvalidated.

Answer in physical units: can the system calculate a push-up, model breathing,
assess an extreme pose's safety, model defecation, or customize male/female
anatomy? Which results are experimentally confirmed? Determine these from the
server's actual capabilities and evidence; do not rely on imagined features.

Use the authoring skill in a separate scratch scenario directory: create a new
valid folder and a malformed one, confirm discovery/quarantine and execute the
valid case. Do not modify production scientific code. Record the prompt, final
answer, tool requests/responses and fetched artifacts. Distinguish a native MCP
connection from any SDK transport bridge used. No patient data, secrets, Git
push, host changes or clinical claims are required.
